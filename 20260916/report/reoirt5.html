웹프로그래밍 개요

웹의 기본 목적

전 세계의 컴퓨터를 연결하여 정보를 손쉽게 공유하고 문서(콘텐츠)를 주고받기 위한 목적입니다.

왜 web인가?

운영체제(Windows, Mac 등)나 기기의 종류에 상관없이 웹 브라우저만 있으면 언제 어디서나 접근할 수 있고, 별도의 프로그램 설치 없이 이용할 수 있기 때문입니다.

웹페이지를 구성하는 3요소
  • HTML (HyperText Markup Language): 웹페이지의 구조(뼈대) 구성
  • CSS (Cascading Style Sheets): 웹페이지의 디자인(시각적 표현) 담당
  • JavaScript: 웹페이지의 동적 기능(상호작용) 구현
